Model. Observed = True × (1 + bsite + drescan + ereader), components independent and Gaussian. bsite is drawn once per site and held across a patient's visits, so it largely cancels in a within-patient change but lands in full against a fixed threshold. ereader is drawn at every read, so it enters twice in any change measure. Sample size from n = 2(z1−α/2+z1−β)2σ2/Δ2. Distributions are Monte Carlo over 20,000 simulated patients per group.
